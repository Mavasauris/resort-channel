Resort Channel Tablet App
Version History
=========================

Versioning is milestone-based.
Only versions explicitly marked STABLE are considered production-ready
for unattended web / tablet kiosk use.

--------------------------------------------------
v0.1.0 — Initial Skeleton
--------------------------------------------------
• Splash / lock screen
• PIN unlock flow
• Profile chooser
• Basic navigation
• Clock and date display

--------------------------------------------------
v0.2.0 — Profile & Navigation
--------------------------------------------------
• Explicit view routing system
• Back button hierarchy
• Profile-based greetings and taglines
• Quote ticker rotation
• Overlay separation (numpad vs content)

--------------------------------------------------
v1.0.0 — Countdown System (STABLE Web Release)
--------------------------------------------------
• Per-profile Disney arrival date storage
• Countdown display page
• Flip-style number animation
• Midnight-safe date calculations
• Countdown configuration overlay
• One-day mode with rotating messages
• Arrival-day mode
• Post-trip mode
• Countdown animation safety guards
• Fireworks overlay integration
• Countdown polish and timing refinements
• Tested as a standalone web app
• Verified stable for long-running tablet/kiosk use
