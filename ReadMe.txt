Resort Channel Tablet App
========================

OVERVIEW
--------
Resort Channel is a custom-built web application designed for
personal, private use as a tablet-based home display.

The app is optimized for long-running, unattended use in a
tablet or kiosk-style environment and intentionally avoids
frameworks or external dependencies.

Primary features include:
• PIN-protected lock screen
• Profile-based experiences
• Disney trip countdown system
• Clock, date, and rotating quotes
• Resort-style informational views (weather, park hours)
• Optional visual effects and ambient animations
