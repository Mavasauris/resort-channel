CHANGELOG
=========

All notable changes are documented here.
Dates reflect when functionality was added or stabilized,
not when code was first experimented with.

--------------------------------------------------
Initial Foundation
--------------------------------------------------
• Basic SPA routing system introduced
• PIN-based unlock screen implemented
• Profile selection system added
• Always-on clock and date display
• Rotating inspirational quotes

--------------------------------------------------
Countdown System
--------------------------------------------------
• Per-profile Disney arrival date storage
• Flip-style countdown digits
• One-day mode with rotating messages
• Arrival-day mode with fireworks
• Post-trip mode with next-trip prompt
• Midnight-safe day calculations
• Countdown animation stability fixes
• Proper cleanup when navigating away

--------------------------------------------------
Resort TV Page
--------------------------------------------------

• Rotating hero slides (parks + Disney Springs)
